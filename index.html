❓ Adding Games

Anyone can add their own HTML games to the launcher.

1. Put your game in the games folder 

games/
├── games.json
├── Bad Apples+.html
├── Dungeons And Dragons.html
└── My Game.html

2. Add your game to games.json 

{
    "name": "My Game",
    "file": "My Game.html",
    "description": "A game I made.",
    "icon": "🎮",
    "category": "Community",
    "author": "Your Name"
}

3. Load the manifest

Put games.json inside the games folder, then start the launcher through your local server.

The launcher will automatically display your game.
